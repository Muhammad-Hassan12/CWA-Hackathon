## 📌 Executive Summary

Traditional civic technology in Pakistan operates as an **intake black hole**: citizens submit complaints into closed government portals where they disappear without statutory routing, public verification, or accountability. Meanwhile, generic LLM wrappers fall into the **hallucination trap**—inventing non-existent laws, confusing Cantonment boundaries with municipal corporations, and failing at utility slab arithmetic.

**Nigraan (نگران)** is an institutional-grade **Civic Intelligence Copilot and Public Ledger** built specifically for Karachi's 16 million residents. It introduces deterministic statutory mandate routing, zero-LLM tariff arithmetic, and a public evidence register that transforms isolated individual grievances into verifiable collective civic weight.

## 🏛️ The 3 Architectural Pillars

### 1. 🔍 Verification Before Generation (Zero Hallucination)
Every civic complaint generated by Nigraan is grounded in actual statutory legislation:
- **Solid Waste:** *Sindh Solid Waste Management Board (SSWMB) Act 2014, Section 8*
- **Water & Drainage:** *Karachi Water & Sewerage Corporation (KWSC) Act 2023*
- **Road Works:** *Sindh Local Government Act 2013 (KMC / TMC Works)*
- **Utility Overbilling:** *NEPRA Consumer Service Manual (CSM) Clause 11*

### 2. 🧮 Zero-LLM Deterministic Arithmetic
Utility bill verification **never uses LLM calculations**. A pure Python tariff engine recomputes consumption against the official **NEPRA July 2024 Gazette** slab by slab, computing statutory Electricity Duty (1.5%), PTV Fee (Rs. 35), and GST (18%) with mathematical precision.

### 3. 📜 Public Ledger Architecture ("Architecture Over App")
Private 1-to-1 complaints are easy for municipal bodies to ignore. Nigraan commits verified complaints and utility audit discrepancies to a **Live Public Evidence Register** powered by PostgreSQL and Realtime feeds, generating municipal authority scorecards and collective corroboration counts.

## 🚀 Key Functional Modules

### 1. 🏙️ Civic Grievance Intelligence Pipeline
- **Multimodal Intake & Map Pinning:** Citizens select hazard categories, upload photos, and pin precise GPS coordinates via OpenStreetMap.
- **Statutory Mandate Matching:** Automatic mapping of the report's sector and hazard type to the mandated administrative body and official helpline.
- **pg_trgm Duplicate Corroboration:** Similar complaints within the same area are clustered together, incrementing citizen confirmation weight rather than spamming redundant tickets.
- **Bilingual Legal Petition:** Generates formal English administrative petitions accompanied by an authentic **خلاصہ برائے فیلڈ انسپکٹر** (Urdu Summary for Field Inspector).
- **Independent Critique Loop:** An explicit second LLM audits the drafted petition against statutory compliance criteria before publishing.
- **Citizen Self-Reported Resolution:** Closes the loop when municipal crews resolve an issue, accompanied by statutory transparency disclosures.

### 2. ⚡ NEPRA & SSGC Utility Bill Audit
- **Multimodal Bill Extraction:** Extracts billed units, category, and amounts from bill images using vision models with instant manual fallback.
- **Slab-by-Slab Mathematical Proof:** Renders an itemized breakdown showing unit costs across protected and unprotected tiers.
- **Statutory Overcharge Detection:** Detects unauthorized overbilling, tariff slab misclassifications, and calculation errors.
- **Formal Dispute Petition Draft:** Produces a ready-to-file legal claim under NEPRA CSM Clause 11 for immediate submission to the utility's Integrated Business Center (IBC) or the NEPRA Consumer Affairs Division.

### 3. 📑 Anti-Hallucination Official Procedure Guide
- **Gazette-Verified Checklists:** Complete requirements, fees, and sequential roadmap steps for high-friction processes (*NADRA CNIC Renewal*, *Sindh Domicile & PRC Form P-1*, *Sindh Police Driving License*).
- **Constraint Gate:** Blocks unverified civic queries to prevent administrative misinformation.
- **Karachi Facilitation Centers Directory:** 24/7 Mega Center addresses, hours, and contact details.
- **Anonymous Exploitation Signal Hotline:** Lets citizens log illegal middleman or bribe demands without storing personal identity details, building systemic municipal pressure metrics.

### 4. 📊 Live Public Evidence Register & Universal Tracking
- **Realtime Evidence Feed:** Live Postgres stream of verified civic complaints and utility disputes across Karachi's 7 districts.
- **Municipal Authority Scorecards:** Real-time performance tracking and citizen backing metrics for SSWMB, KWSC, KMC, CBC, and K-Electric.
- **Universal Audit Lookup:** Universal search across all tracking IDs (`KOR-2026-0042`, `KE-2026-8812`) to inspect the complete evidence record and statutory draft.
- **Agent Trace Inspector:** Live interactive visual inspector of the internal LangGraph DAG execution steps for full transparency.

## ⚡ Quickstart & Local Setup

### 1. Prerequisites
- **Node.js** (v18+) & **npm**
- **Python** (v3.10+)
- **Supabase Account** (or local PostgreSQL)

---

### 2. Database Setup
1. Create a new project in [Supabase](https://supabase.com).
2. Open the **SQL Editor** and run `database/schema.sql` to create tables and indexes.
3. Run `database/seed_data.sql` to populate Karachi authority mandates, NEPRA tariff schedules, and verified procedure records.

---

### 3. Backend Setup

```bash
# Navigate to backend
cd backend

# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
```

Edit `backend/.env` with your API credentials:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-or-service-key
GROQ_API_KEY=your-groq-api-key
GEMINI_API_KEY=your-gemini-api-key
PORT=8008
HOST=0.0.0.0
```

Start the backend server:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8008 --reload
```
API Documentation will be live at: `http://localhost:8008/docs`

---

### 4. Frontend Setup

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start Vite development server
npm run dev
```
Open `http://localhost:5173` in your browser.

To test production build:
```bash
npm run build
```

## 🛡️ Anti-Hallucination & Citizen Privacy Directives

1. **Zero Citizen Identity in Exploitation Signals:** The `exploitation_signals` table stores **zero citizen identity fields** (no names, no phone numbers, no CNIC). Data is processed purely as aggregate pressure heatmaps.
2. **Deterministic Fallback Engine:** If external LLM provider APIs encounter rate limits or network outages, Nigraan's local rule-based engine and offline procedure registry ensure seamless, uninterrupted execution.
3. **Transparent Resolution Disclosures:** Any citizen-marked resolution carries a mandatory statutory disclosure stating it is self-reported, preventing false municipal closure claims.
